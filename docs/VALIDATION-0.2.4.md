## 修改

- 图表按当前窗口实际宽、高绘制，文字按 sp，点与线按 dp，无非等比画布缩放。标题、选中值、统计分行；横轴刻度按宽度安排。支持窄手机、横屏、平板及分屏窗口；窗口变化重新测量高度。
- 增加纵轴数字。CPU / GPU 使用率和电量为 0–100%；异常原始值有越界提示和边界标记。FPS 及轻帧单核当量 CPU 的上限覆盖实际峰值，不能以 165fps 或 100% 裁剪。
- 触摸与缩放按实际绘图区计算；PNG 使用同一渲染器的独立几何，不会改变屏幕选点坐标。
- 过期呈现窗口的 FPS 为空，另存 frameWindowStale 与原因；不再用伪 0 进入平均。真实 1 / 0.5fps 和长卡顿的呈现间隔保留。
- 对旧记录只在同一行能证明无有效窗口时排除 0 FPS，并报告排除数量。曲线、区间和全记录统计使用一致规则，摘要分析版本升为 2；原始 CSV 不修改。证据不足的旧 0 不盲目删除。
- 帧 / 硬件 / 温度间隔可手动填写整数毫秒，范围分别 50–5000、100–60000、500–60000。保存前整体验证，解释小间隔的开销和大间隔的峰值遗漏 / 缓冲缺口；下一次记录生效。
- 主页新增采集授权向导，集中状态检测、Shizuku 启动 / 授权、返回后复检。内置无线 ADB 的研究见 ACCESS-OPTIONS.md，本版未加入可用内置启动器。
- 手动诊断增加 Perfetto 只读数据源查询：3 秒 / 128KB 限额，超时 / 取消清理；不启动追踪，不添加正常录制负担，也不宣称恢复 GPU 利用率。
- 无有效图层时清除旧来源验证与探测计数，避免缓存状态残留。
